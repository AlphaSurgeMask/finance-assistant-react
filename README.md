# Finance Assistant (react)

A react-native/expo project with the idea of helping people reduce subscription waste.

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

## Other steps

1. Check for linting problems

   ```bash
   npx expo lint
   ```
2. Install packages for React Native DevTools (if using codespaces)

   ```bash
   sudo apt update
   sudo apt upgrade

   sudo apt install \
     libatk1.0-0 \
     libatk-bridge2.0-0 \
     libcups2 \
     libgtk-3-0 \
     libgbm1 \
     libasound2t64
   ```
